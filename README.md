# Graph Database Cloud Benchmark

Reproducible benchmarking of CognoDB Cloud against managed graph database platforms using identical datasets and workloads.

## Objective

This project benchmarks CognoDB Cloud against other managed graph database platforms using the same dataset and equivalent workloads.

The goal is to evaluate:

- Query performance
- Data ingestion performance
- Scalability
- Resource usage
- Cost considerations

The benchmark is designed to be reproducible, fair, and transparent.

## Platforms

- CognoDB Cloud
- Neo4j Aura
- Amazon Neptune
